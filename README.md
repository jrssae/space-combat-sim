Exploring a 3d space combat simulator using Newtonian physics (with simplified gravity).  

I am still disappointed I never got to play the Bablyon 5 game created by Sierra in the early 2000s. This is my attempt to recreate what I was hoping for in that game.  This is a fan project and is not intended for any commercial use. All assets are generated by an AI, and since AI is trained on public data, this is being kept open source.  

The following projects were used for inspiration. All assets were generated from scratch but compared against screenshots from the show, STL models, and other fan art. This project wouldn't have been possible without these creators' work.

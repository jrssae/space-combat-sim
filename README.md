Exploring a 3d space combat simulator using Newtonian physics.  

I am still disappointed I never got to play the Bablyon 5 game created by Sierra in the early 2000s. This is my attempt to recreate what I was hoping for in that game.  

I also recently saw some videos about gaussian splats and thought it sounded intriguing, so that's the reason for the technology choice. Sticking with godot to keep it open source.
